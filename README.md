# table-web-page

Una página web sencilla y responsive creada con HTML, CSS y JavaScript.

## Estructura

- `index.html`: contenido principal de la página
- `styles.css`: estilos y diseño visual
- `script.js`: interacciones pequeñas y scroll suave

## Cómo empezar

1. Abre la carpeta del proyecto en VS Code.
2. Ejecuta un servidor local desde la terminal:

```bash
cd /workspaces/table-web-page
python3 -m http.server 8000
```

3. Abre en tu navegador:

```text
http://localhost:8000
```

## Personalizarlo

- Cambia el texto en `index.html`
- Ajusta colores, spacing y layout en `styles.css`
- Añade comportamientos extra en `script.js`

## Siguiente paso recomendado

Si quieres, puedes convertir esta base en una landing page, portafolio o tienda simple añadiendo secciones, imágenes y formularios.
